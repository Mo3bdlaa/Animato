SCREEN 2 Library — All lens · Anime lens · filter sheet
Decisions
· The lens is the same top-bar icon as Home v2 — one circle, full for All and half-shaded blue when filtered — so Library's only chip row is categories. That is what the second row was always for; two chip rows was the thing design.md bans.
· The counts I pulled off Home live in those chips — on the selected chip only (All 95, and 39 under the Anime lens). Four chips each carrying a count came to 435 dp and sliced the last number at the 393 edge; the count belongs to the category you are actually in.. A number next to the thing it filters is content; a number in a card of its own was decoration.
· Grid is 3 × 112 with 12 dp gaps (16 + 3×112 + 2×12 + 16 = 393 exactly). Titles sit below the cover here, 2-line clamp, 40 dp reserved on every card — a grid ellipsizes titles constantly, and Compose needs one row height, not a text-dependent one.
· Category selection is #FFFFFF14 fill + white label, not blue. Blue on this screen is the unread pills (one repeated system element) and the Library tab. 3c spends it on the selected sort radio and the switch instead.
Notes for you
· 3b proves the lens: type chips vanish, captions turn into Ep., and the count in All 39 drops to the anime subset. Flip Home's lens tweak and this is the pair the brief asks for.
· Sheet is 618 dp (measured content, not estimated — top edge at 234), 28 dp top radius, three titled sections. It has no Apply button — filters apply live and the scrim dismisses, so the one primary slot stays free. Reset is the outlined secondary.
· Sort options avoid media words: Recently updated · Recently opened · Title A–Z.
· 3e is the long-press quick sheet: five actions, each with a caption that states its consequence — Chapters 1–254, ≈ 58 MB, Keeps 3 downloaded chapters — asks first. Continue is the only blue glyph, because it is the only one that resumes something; Remove is not red, since the confirmation is where the danger lives, not the label.
Category chips map to real data, not tracker status. All is every saved title. Ongoing, Backlog and Finished are the three default user categories seeded at first run — editable and renameable in Settings › Library › Categories, and the row only renders when more than one category exists. If a person deletes them, their own names appear here instead. Derived states (Unread, Downloaded, Started, Tracked) stay in the filter sheet, because they are not categories and a title can be in several at once.
