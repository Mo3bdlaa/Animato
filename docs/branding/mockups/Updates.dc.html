SCREEN 8 Updates — day-grouped feed · swipe affordances · empty
Decisions
· Day headers are 13 Medium Muted, 32 dp, sticky — not the 18 SemiBold section header. A date is a divider, not a section title, and at 18 the feed reads as five headlines with rows attached. This is a size design.md does not specify; flag it if you want 18.
· Rows are the design.md update row exactly: 48 dp thumb r12, 15 Medium title, 13 Muted caption, timestamp then NEW pill or download glyph on the trailing edge — identical to Home's Latest updates, because they are the same object.
· 5b shows both swipe directions on real rows: leading reveals Opened, trailing reveals Download. Action backgrounds are #FFFFFF14 with white glyphs — swipe is a gesture, not a state, so it gets no blue.
Notes for you
· Top bar: title, lens icon, refresh. No calendar icon — the feed is the calendar, and the old app's calendar button opened a screen the brief does not list.
· Blue budget: 5a and 5b one (Updates tab). 5c two (Updates tab, the one primary). NEW pills stay Accent.
· 5c replaces the old kaomoji empty state — brand illustration, one sentence, one button, per design.md.
· Captions name the item's own unit (Chapter 1187 / Episode 1123); the shared labels around them stay neutral.
