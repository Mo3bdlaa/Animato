SCREEN 3 Discover — top of screen · scrolled to sources with zero installed
Decisions
· Search is a real field here (48 dp, r24, Surface) because Discover starts with a query, not a title. The lens icon sits outside it, same slot as Home and Library.
· Three rails, one rhythm: 112 × 168 covers, title 15 Medium one line, caption 13 Muted. Rail geometry 16 + 3×112 + 2×12 = 376, so the fourth card peeks 17 dp and no card is cut mid-title.
· The rails do not depend on sources — that is the whole point of 4b. Public metadata fills Trending / This season / Top rated; only the Your sources block goes empty.
· Zero-sources card is the one place manga DNA is allowed on this screen (halftone burst, speed lines) and it holds the single primary: Add sources. Under it, Suggested lists both media — two manga sources and two anime — with the type chip on the meta line and an outlined Add per row, so the empty state never reads as a manga app waiting for manga.
Notes for you
· 4b is the same screen scrolled 380 dp, not a different screen — the tail of Top rated is deliberately cut at the top edge, which is what a scrolled Compose LazyColumn looks like.
· Blue budget: 4a two (Discover tab, nothing else — rails are metadata, not progress). 4b two (Add sources, Discover tab).
· Source rows carry language + type chip and a pin, per design.md §Components; the full Sources screen is #6 in the brief and reuses this row verbatim.
Ratings: brand sheet shows ★ 9.1 on the title page, design.md has no rating token. I used it as caption text in Top rated only, Muted 13, no colour. Say if you want it gone.
