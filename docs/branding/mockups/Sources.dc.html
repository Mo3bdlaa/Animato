SCREEN 6 Sources & extensions — Installed · Available · ships-empty
Decisions
· The type chip is on every row, always — the one place it ignores the lens. UX.md is explicit: this screen is the answer to “there is no way to tell anime and manga extensions apart”, so the chip cannot be a thing that disappears. The lens still filters which rows appear — flip the Lens tweak and the list drops to two rows.
· Segments are the Title-page tab pattern (15 Medium, 2 dp blue underline), not chips. Chips are the lens/category component; borrowing them here would put two chip-shaped rows on one screen, which design.md forbids.
· Repositories sits above the segments, not inside Available: it is where content comes from, so it governs both lists. Its caption carries the count and the verb.
· Rows are 72 dp: 40 dp icon, title 15 Medium, then one caption line that holds the type chip, the language and the version. Trailing is pin + gear, 48 each — the Update pill rides at the end of the caption line so no row grows a third control.
· Every row is one tap from its own settings; no row is a button. Install is an outlined pill, because one primary per screen and on 10c that primary is Browse available.
Notes for you
· Blue count — 10a two (active segment, pinned star). 10b one (active segment). 10c two (active segment, Browse available). No bottom bar: this is a sub-screen off Discover › Manage and Settings › Sources.
· Update pill uses Warning #F59E0B on Ink Black text — the NEW pill's shape and weight, a different token, because an available update is attention and not novelty. Blue was not available and would have lied.
· NSFW is marked in plain words — the literal string NSFW in Warning — never an icon, never a colour-only cue.
· Available is grouped by language with Arabic first, matching the onboarding rule that Arabic is listed prominently rather than alphabetically buried.
One value not in design.md: the 40 dp source icon (r12) — smaller than the 48 dp update thumb, because a source icon is a logo and not artwork. Confirm and I will add it.
